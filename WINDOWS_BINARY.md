# Windows 可执行文件 / Windows binary

## 直接下载

无需安装 Python，下载后直接运行：

**[下载 RapidClick.exe](../../releases/latest/download/RapidClick.exe)**

- 系统要求：64 位 Windows 10/11
- 校验文件：[RapidClick.exe.sha256](../../releases/latest/download/RapidClick.exe.sha256)
- 如 SmartScreen 提示未识别应用，请先核对 Release 页面与校验文件中的 SHA-256
- 本程序不会安装服务、添加开机启动项或写入系统目录

## 从源码打包

在 Windows PowerShell 中运行 build.ps1。打包使用 PyInstaller 6.22.3，输出位于 dist/RapidClick.exe。
